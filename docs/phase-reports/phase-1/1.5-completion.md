## Decisions Made
- Every major technology selection is bound to an explicit ADR explaining context, problem, options considered, selection rationale, rejected alternatives, trade-offs, and consequences.
- Standardized on TypeScript across the full stack using Turborepo and pnpm.
- Unified relational, document (JSONB), and vector embeddings into a single PostgreSQL 16+ engine.
