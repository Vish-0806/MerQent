## 2. Area 1: Constant-Time Comparison Safety & Key Length Invariance

### 2.1. Vulnerability Analysis
In Node.js, `crypto.timingSafeEqual(bufA, bufB)` requires `bufA.length === bufB.length`. If buffers have different lengths, the runtime immediately throws:
```
RangeError: Input buffers must have the same length
```
If an unhandled length mismatch occurs, the NestJS request lifecycle could escalate into an unhandled exception (`HTTP 500 Internal Server Error`), or alternatively, returning early on `bufA.length !== bufB.length` creates a timing side-channel that allows attackers to determine the exact character length of `METRICS_SCRAPE_KEY` via statistical timing analysis.

### 2.2. Hardened Implementation (`safeCompare`)
[`MetricsAuthGuard`](file:///c:/Users/Vishal%20S%20Naik/MyProjects/MerQent/apps/api/src/infrastructure/observability/metrics-auth.guard.ts) now employs dummy timing equalization and defensive error suppression:
```typescript
private safeCompare(candidate: string, target: string): boolean {
  if (!candidate || !target) return false;
  try {
    const bufCandidate = Buffer.from(candidate, 'utf8');
    const bufTarget = Buffer.from(target, 'utf8');

    if (bufCandidate.length !== bufTarget.length) {
      // Execute dummy comparison against target buffer to equalize timing profile
      // and prevent length-oracle timing side-channels
      crypto.timingSafeEqual(bufTarget, bufTarget);
      return false;
    }

    return crypto.timingSafeEqual(bufCandidate, bufTarget);
  } catch {
    return false;
  }
}
```

### 2.3. Key Length Variation Testing
Verified across unit tests and live E2E HTTP server:
- Single-byte keys (`'a'`, `'1'`): returns `HTTP 401 Unauthorized`.
- Short keys (`'short-key'`, `VALID_KEY.slice(0, 10)`): returns `HTTP 401 Unauthorized`.
- Extended keys (`VALID_KEY + 'suffix'`): returns `HTTP 401 Unauthorized`.
- Very large keys (256 bytes, 1024 bytes): returns `HTTP 401 Unauthorized`.
- Equal-length mismatched keys (`'x'.repeat(KEY.length)`): returns `HTTP 401 Unauthorized` in constant time.
- Exact match key: returns `HTTP 200 OK`.
- **Zero HTTP 500 errors or uncaught exceptions observed.**

## 3. Area 2: Production Secret Validation & Fail-Closed Boundaries

### 3.1. Production Environment Schema Rule (`env.schema.ts`)
In [`apps/api/src/config/env.schema.ts`](file:///c:/Users/Vishal%20S%20Naik/MyProjects/MerQent/apps/api/src/config/env.schema.ts), a `.superRefine` rule was added:
```typescript
.superRefine((data, ctx) => {
  if (data.NODE_ENV === 'production') {
    const scrapeKey = data.METRICS_SCRAPE_KEY?.trim();
    if (scrapeKey && scrapeKey.length > 0 && scrapeKey.length < 32) {
      ctx.addIssue({
        code: z.ZodIssueCode.custom,
        path: ['METRICS_SCRAPE_KEY'],
        message:
          'In production, METRICS_SCRAPE_KEY must be at least 32 characters long when configured for monitoring access',
      });
    }
  }
});
```

### 3.2. Behavioral Boundaries
1. **Local Development & Test Environments (`NODE_ENV !== 'production'`)**:
   - `METRICS_SCRAPE_KEY` remains optional and can be empty or of arbitrary length.
   - Developers are not forced to generate 32-character secrets for local testing.
2. **Production Deployment (`NODE_ENV === 'production'`)**:
   - **Weak Secret (< 32 chars)**: Environment validation fails at startup with an explicit message:
     `"In production, METRICS_SCRAPE_KEY must be at least 32 characters long when configured for monitoring access"`.
     The attempted secret is never included in the error message.
   - **Unconfigured / Empty Secret (`METRICS_SCRAPE_KEY=''` or omitted)**:
     The application boots cleanly, allowing public health probes (`/health`, `/health/ready`) to operate.
     However, M2M monitoring authentication **fails closed by default**: any request to scrape metrics via `x-metrics-key` or Bearer scraper key is rejected with `HTTP 401 Unauthorized` (`"Machine-to-machine metrics authentication is not configured on this server"`).
   - **Valid Secret (>= 32 chars)**:
     Passes validation and allows authorized monitoring scrapers.
