## 3. Detailed Advisory Analysis & Remediation Matrix

### 3.1. Primary Target Advisories

#### 1. `GHSA-p293-qw3h-jr36` (CVE-2026-75604) — Remote Code Execution via Path Traversal on Windows
- **Severity**: Critical (CVSS 9.8)
- **Affected Range**: `>= 13.4.0, < 15.5.24` / `< 16.3.3`
- **Root Cause & Vulnerability Mechanism**: An internal route handler flaw in Next.js Windows file path resolution allowed path traversal sequences (`..\\` and UNC path handling) during dynamic route asset serving, leading to arbitrary code execution or local file inclusion.
- **Applicability to MerQent**: **Directly Applicable**. While production containers run on Linux (`node:20-alpine`), local developer environments and Windows hosts run Windows workstations. In accordance with task requirements ("Do not assume Linux deployment automatically eliminates a vulnerability"), Windows workstations and hybrid routing were directly vulnerable.
- **Remediation**: Upgraded Next.js to `15.5.27`. Path normalization and traversal guards introduced in `15.5.24` fully patch this vulnerability.
- **Remaining Status**: **RESOLVED** (Eliminated from `pnpm audit`).

#### 2. `GHSA-2xp9-vwfh-vxw4` — Critical Remote Code Execution in Image Optimization
- **Severity**: Critical (CVSS 9.5)
- **Affected Range**: `>= 10.0.0, < 15.5.24` / `< 16.3.3`
- **Root Cause & Vulnerability Mechanism**: Heap-based buffer overflow in image optimization pipeline during AVIF/HEIC format decoding via upstream image parsing libraries. Specially crafted image upload payloads could trigger memory corruption and arbitrary code execution in the Node.js server process.
- **Applicability to MerQent**: **Directly Applicable**. Even though `next.config.js` specifies `images: { unoptimized: true }`, the underlying image optimizer handler endpoints remain packaged and active within Next.js server runtime bundles.
- **Remediation**: Upgraded Next.js to `15.5.27`. The updated internal image decoder sanitizes input buffers and bounds checks memory allocations.
- **Remaining Status**: **RESOLVED** (Eliminated from `pnpm audit`).

#### 3. `GHSA-89xv-2m56-2m9x` (CVE-2026-64649) — Server-Side Request Forgery via Server Actions
- **Severity**: High (CVSS 8.2)
- **Affected Range**: `>= 14.1.1, < 15.5.21` / `< 16.2.11`
- **Root Cause & Vulnerability Mechanism**: Next.js Server Action redirect handling permitted untrusted `Host` and `X-Forwarded-Host` HTTP header poisoning, allowing attackers to coerce server-side requests to internal RFC 1918 infrastructure or arbitrary external endpoints.
- **Applicability to MerQent**: **Directly Applicable**. MerQent's web frontend is designed for enterprise PMI workflows with strict reverse-proxy headers and backend API proxying.
- **Remediation**: Upgraded Next.js to `15.5.27`. Server Action redirect destination validation now strictly matches configured allowed origins and host headers.
- **Remaining Status**: **RESOLVED** (Eliminated from `pnpm audit`).
