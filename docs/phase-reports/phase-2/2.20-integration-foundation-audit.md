## 7. Prioritized Remediation Plan

### Tier 1: Production Blockers (Must resolve before public deployment)
1. **Deploy Active Malware Scanner Daemon**: Provision ClamAV daemon service container in production infrastructure and update `STORAGE_MALWARE_SCANNER_URL`.
2. **Upgrade Next.js Framework**: Monitor Vercel releases and upgrade to a patched version (>=15.5.24) once monorepo compatibility is verified.
3. **Configure Cloud Infrastructure Secrets**: Provision AWS IAM OIDC roles (`AWS_ROLE_TO_ASSUME`), ECR registries, and ECS cluster identifiers in GitHub Secrets.
4. **Harden Database Reset Scripts**: Add strict environment validation in `reset-db.ps1` and `reset-db.sh` rejecting execution if `NODE_ENV === 'production'`.

### Tier 2: Pre-Production Hardening Improvements (Recommended during Phase 3)
1. **Secure Telemetry Endpoint**: Add bearer token authentication or network ingress restriction to `/api/v1/metrics`.
2. **Jest Worker Teardown Cleanup**: Ensure all background interval timers in tests call `.unref()` to eliminate worker exit warnings.
3. **Database Backup & Point-in-Time Recovery**: Establish automated PostgreSQL pg_dump / WAL archiving scripts in infrastructure automation.
